# 模块目录与边界

## Dashboard

职责：聚合各模块公开的摘要信息，编排今日视图。  
不负责：直接修改学习、英语或健身内部数据。

## Learning

职责：职业能力路线、学习计划、知识点掌握、学习记录和复盘。  
公开输出：今日学习任务、学习进度摘要。  
不负责：知识文档底层解析和具体模型调用。

## English

职责：技术阅读、词汇、表达和面试英语任务与反馈。  
公开输出：今日英语任务、能力摘要。  
不负责：通用学习计划的全部逻辑。

## Fitness

职责：身体档案、测量记录、肌群选择、训练计划、训练执行和恢复反馈。  
公开输出：今日训练、恢复摘要。  
不负责：医学诊断、康复处方或图片身份识别。

## Knowledge

职责：资源上传、解析、分块、索引、检索、引用和用户可控记忆。  
公开接口：导入资源、检索知识、删除资源、查看来源。  
不负责：取代业务数据库保存精确指标。

## LLM Provider

职责：Provider 配置、统一调用契约、路由、超时、重试、错误与使用记录。  
公开接口：生成文本、生成结构化结果、生成向量。  
不负责：学习或健身领域规则。

## Shared

职责：无业务含义的 UI、基础类型和通用工具。  
规则：不能成为“什么都放”的目录；包含业务词汇的代码应留在所属模块。
