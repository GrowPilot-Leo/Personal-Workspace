# GrowPilot 产品说明 V0.1

## 1. 产品定位

GrowPilot 是面向职业成长型用户的 AI Personal Growth OS。它把学习、英语、身体训练和个人知识沉淀放进同一套每日行动闭环，但各业务模块保持独立。

核心价值不是“提供多个聊天窗口”，而是持续记录目标、行动和反馈，让 AI 在获得明确上下文后给出可执行建议。

## 2. 核心用户

首要用户是正在提升 AI 产品能力、准备求职并保持规律训练的个人用户。V0.x 阶段先服务单用户场景，不提前扩展团队协作、社交、财务或娱乐功能。

## 3. 核心使用闭环

1. 用户设定阶段目标与当日可用时间。
2. Dashboard 汇总各模块的今日行动。
3. 用户进入具体模块执行任务并记录结果。
4. 系统保存结构化记录，AI 对结果进行总结和反馈。
5. 次日计划根据目标、历史和未完成项调整。

## 4. 首版范围

### Dashboard

- 展示今日任务、完成度和成长维度。
- 提供各模块入口。
- 展示系统建议占位，后续由规则与 AI 服务共同生成。

### Learning

- 展示 AI 产品经理学习路线。
- 预留学习计划、知识点掌握度和每日复盘接口。

### English

- 展示职业英语训练任务。
- 预留阅读、词汇、口语和写作评分结构。

### Fitness

- 展示身体档案和训练目标入口。
- 预留 2D SVG 肌群选择、训练计划和训练记录。
- V0.1 不进行照片体态诊断，不承诺医学或康复建议。

### Knowledge

- 展示文本、图片、PDF 等导入入口占位。
- 后续实现解析、元数据、分块、向量化、检索和引用。
- 用户事实、身体指标、任务状态等结构化数据不依赖 RAG 保存。

### LLM Provider

- 展示模型供应商配置入口。
- 默认优先支持 DeepSeek，后续支持其他兼容 Provider。
- API Key 只在服务端读取，不写入浏览器或仓库。

## 5. 非目标

V0.1 不包含真实登录、支付、多人协作、完整 Agent 编排、3D 人体模型、医学判断和自动化外部写入。

## 6. 成功标准

V0.1 的成功标准是：项目可启动、模块入口清晰、各模块互不耦合、后续功能可以在模块内部扩展。此阶段不虚构活跃度、成长分数或 AI 效果指标。
