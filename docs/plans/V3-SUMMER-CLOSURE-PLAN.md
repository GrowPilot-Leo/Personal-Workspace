# V3 核心闭环与夏日主题实施计划

## 目标

把当前“日循环 MVP + 九模块壳层”收敛为可验收的高频闭环，并为白天主题建立清晰、克制的夏日海滩视觉语言。

## 产品范围

### P0 核心闭环

1. Today 按任务状态给出唯一主行动：创建计划、开始下一项、开始复盘。
2. Today 支持直接完成/撤销任务，结果写回统一 WorkspaceRepository。
3. Review 读取并保存真实每日复盘，展示最近记录与 7 日摘要，并负责“归档并开始下一天”。
4. Settings 提供真实主题、动效、本地数据导出/导入/清空。
5. 移动端底部导航调整为 Today / Learning / Review / Knowledge / Settings。
6. 规则生成内容统一改名为“行动建议”，不再冒充 AI。

### 白天夏日主题

- 海水蓝：主操作和选中态。
- 阳光黄：小黄鸭、提示和局部强调。
- 浅沙色：页面背景暖色收口。
- 透明渐变：仅用于壳层和交互控件，业务内容卡片保持高对比度。
- 小黄鸭/泳圈：只放在高价值主按钮或状态点，不装饰每个控件。
- 动效：使用短距离、低弹跳的 spring/press 反馈；完整尊重 reduced/off/system。

## 明确不做

- 不在本轮实现真实 AI/RAG、登录、云同步。
- 不扩张 Career / English / Fitness / Badge 的业务范围。
- 不把壁纸图片放在文字内容后方，避免牺牲可读性。

## 验收标准

1. 新用户能从 Today 进入 Learning 建立计划。
2. 有任务时能在 Today 开始并直接完成下一项。
3. 完成后可进入 Review 保存复盘并结转下一天。
4. Settings 的主题、动效、导入导出和清空数据均有真实动作与反馈。
5. 390px 下无横向溢出，底部导航展示五个高频入口。
6. 夏日主题正文与卡片对比清晰，夜间/暮色不被夏日视觉污染。
7. E2E 覆盖 Today、Review、Settings、主题、移动导航和 axe。
