# V3 Calm Timeline 视觉重构计划

## 设计命题

将产品从具象夏日装饰重构为成熟、安静、可长期使用的个人成长工作台。

- Things：留白、文本层级、安静的任务操作。
- Sunsama：晨间计划、专注执行、晚间复盘的流程引导。
- Structured：一眼可读的纵向今日时间线。

以上只作为设计原则，不复制品牌素材或界面。

## 视觉系统

- 日间画布：暖灰白，内容面为纯白。
- 主色：克制的系统蓝；颜色只表达操作、进度和状态。
- 按钮：纯色、描边、文字三级体系；移除渐变、Emoji 和装饰性浮动。
- 卡片：低圆角、细边框、极轻阴影；避免所有信息都被包成卡片。
- 图标：统一 Lucide 线性图标。
- 动效：160–240ms，只有状态变化、展开、抽屉和任务完成；无漂浮和弹跳装饰。

## Today 信息架构

1. 页头：日期、阶段目标、唯一主操作。
2. 今日节奏：计划 → 执行 → 复盘，显示当前阶段。
3. 主区左侧：纵向时间线，任务按预计时长顺序排列并可直接完成。
4. 主区右侧：今日目标、工作量、规则建议和复盘入口。
5. 移动端：时间线优先，辅助信息自然下沉。

## 验收标准

- 页面第一视觉焦点是“下一项行动”，不是装饰。
- 同一视口内不超过一个实心主按钮。
- 日间主题无渐变主按钮、无 Emoji、无海滩/泳圈具象元素。
- 任务状态能在时间线上直接识别和修改。
- 390px、桌面端与三主题可读。
- system/reduced/off 动效偏好继续有效。
